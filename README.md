# Telegram Data Analyst Userbot

Асинхронный Telegram-юзербот для личного использования, автоматизирующий сбор контекста рабочих переписок, обработку скриншотов с графиками и генерацию структурированных саммари. Скрипт работает полностью локально, обеспечивая конфиденциальность анализируемых данных без отправки трафика на внешние сторонние серверы.


## Стек технологий
* **Язык разработки:** Python 3.10+ (совместим с 3.14)
* **Telegram API Framework:** Pyrogram v2.0+ (авторизация по протоколу MTProto через системный обход сетевых ограничений)
* **Локальный ИИ-движок:** Ollama API
* **Модель анализа данных:** DeepSeek-R1 (конфигурация 1.5b параметров)
* **Среда прототипирования:** Jupyter Notebooks (`ipykernel`)
* **Обработка медиа:** Pillow

## Архитектура пайплайна данных
1. **Перехват триггера:** Скрипт слушает входящий поток сообщений и активируется строго по команде `.summary`, отправленной владельцем аккаунта.
2. **Экстракция контекста:** Юзербот извлекает историю последних 50 сообщений из текущего диалога, формируя хронологический текстовый лог.
3. **Обработка графиков:** Если в рамках извлеченной истории присутствует скриншот или изображение, скрипт автоматически скачивает медиафайл во временную директорию `src/temp_downloads/`.
4. **Интеграция с LLM:** Текстовый контекст и путь к изображению передаются в асинхронный клиент Ollama для мультимодального анализа моделью `deepseek-r1:1.5b`.
5. **Пост-обработка (Парсинг):** На этапе вывода текста применяется регулярное выражение для очистки ответа от служебных тегов глубокого размышления `<think>...</think>`.
6. **Автоочистка памяти:** После отправки ответа в чат Telegram временный медиафайл принудительно удаляется с диска (`os.remove`) для оптимизации дискового пространства.

## Структура проекта
* `src/` — исходный код приложения.
  * `bot/handlers.py` — регистрация фильтров сообщений, сбор истории и скачивание скриншотов.
  * `models/ollama_client.py` — коннектор к локальной LLM, системный промпт аналитика и очистка тегов think.
  * `main.py` — асинхронная точка входа, бесконфликтная инициализация event loop в Python 3.14.
  * `auth.py` — утилита первичной авторизации аккаунта с эмуляцией мобильного устройства для обхода флуд-контроля.
* `tests/` — папка интерактивных исследований.
  * `scratchpad.ipynb` — черновик для быстрых тестов сетевых сокетов и прокси.
  * `clean_research.ipynb` — чистый лог успешных запусков и фиксации результатов работы ИИ.
* `.env` — конфигурационный файл (api_id, api_hash). Защищен от фиксации в репозитории через `.gitignore`.

## Инструкция по развертыванию

### 1. Подготовка локального ИИ сервера
Установите Ollama и скачайте веса модели в терминале:
```bash
ollama run deepseek-r1:1.5b
```

### 2. Клонирование и настройка окружения
```bash
git clone https://github.com
cd tg-analyst-userbot
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install pyrogram ollama ipykernel Pillow python-dotenv
```

### 3. Настройка конфигурации
Создайте файл `.env` в корне проекта:
```text
API_ID=2040
API_HASH=b18441a1ff607e10a989891a5462e627
```

### 4. Инициализация сессии и запуск
При первом запуске при включенном системном VPN выполните скрипт авторизации и введите номер телефона и код подтверждения из приложения Telegram:
```bash
python src/auth.py
```
После генерации файла сессии запустите юзербот в постоянном режиме:
```bash
python src/main.py
```

## Использование
В любом рабочем чате или канале введите команду:
```text
.summary
```
Юзербот преобразует сообщение в статус выполнения, соберет контекст и выдаст структурированный технический отчет (Задачи, Договоренности, Проблемы, Метрики).
