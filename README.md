## Как работает текущая версия

1. `main.py` запускает Pyrogram-клиент.
2. `src/bot/handlers.py` распределяет входящие команды от владельца аккаунта:
   - Команда `.summary` собирает историю и отправляет её в локальную Ollama. Отчёт маркируется меткой `[Локальный ИИ]`.
   - Команда `.summary_api` собирает историю и отправляет её в Yandex AI Studio. Отчёт маркируется меткой `[Облачный API]`.
3. Обработчик собирает до 50 последних сообщений, включая текст и подписи к медиа, разворачивает их в хронологическом порядке и скрытно удаляет исходную команду из рабочего чата.
4. Для изображений сейчас определяется только факт наличия: файлы не скачиваются и моделям не передаются.
5. Выбранный клиент ИИ очищает ответ от лишних тегов (включая удаление многострочных блоков `<think>` для локальной модели) и пересылает структурированное саммари (тема, решения, задачи, открытые вопросы) в «Избранное».

## Активные файлы

- `main.py` — точка входа приложения.
- `src/auth.py` — вход в Telegram и создание локальной сессии с мобильным спуфингом.
- `src/bot/handlers.py` — единый оркестратор команд, сбора истории чата, вызова моделей и вывода расширенного traceback в случае ошибок.
- `src/models/yandex_client.py` — текстовый клиент Yandex AI Studio (Qwen3.6 35B) с защитой API-ключей в логах.
- `src/models/ollama_client.py` — локальный асинхронный клиент Ollama (Qwen2.5 3B) с регулярным выражением для очистки мыслей модели.
- `.env` — локальные секреты (`API_ID`, `API_HASH`, `YANDEX_CLOUD_API_KEY`, `YANDEX_CLOUD_FOLDER`); файл игнорируется Git.
- `src/analyst_userbot.session*` — локальная Telegram-сессия; секрет, полностью исключён из индекса репозитория через `.gitignore`.

## Архив экспериментов

## Запуск

1. Установите зависимости в виртуальное окружение: `pyrogram`, `httpx`, `python-dotenv`.
2. Убедитесь, что локальная Ollama запущена и модель скачана: `ollama run qwen2.5:3b`.
3. Проверьте локальный `.env`: для облачного клиента нужны `YANDEX_CLOUD_API_KEY` и `YANDEX_CLOUD_FOLDER`. Не публикуйте файл и не вставляйте секреты in сообщения.
4. После отзыва старых Telegram-сессий, когда будете готовы к сквозной проверке, создайте новую:

```powershell
python .\\src\\auth.py
```

5. Запустите приложение из корня проекта:

```powershell
python .\\main.py
```

6. В нужном чате отправьте `.summary` для локального разбора или `.summary_api` для облачного анализа.

Текущий этап — гибридное текстовое саммари (Ollama/Yandex). Следующий отдельный этап — скачивать выбранные изображения и передавать их в мультимодальный контракт Yandex AI Studio вместе с текстом.
